# 🎓 Student Management System in C

A simple **Student Management System** developed using the **C programming language**.
This project allows users to manage student records through a menu-driven console application.

## 🚀 Features

* ➕ Add Student
* 📋 Display Students
* 🔍 Search Student
* ✏️ Update Student
* 🗑️ Delete Student
* 🚪 Exit

## 🛠️ Technologies Used

* C Programming
* Structures
* Arrays
* Functions
* File Handling

## 📚 Concepts Covered

This project helps practice:

* `struct`
* Arrays
* Functions
* Loops
* Conditional statements
* File handling
* Menu-driven programming

## ▶️ How to Run

### Compile

```bash
gcc student_management.c -o student_management
```

### Run

```bash
./student_management
```
